As a Front-End developer at Cliqx, I worked on several projects, mostly software for the retail market. My main contribution was structuring an application for Pernambucanas, where I proposed the use of the Nuxt3 framework and collaborated on the application development using a hexagonal architecture with service layers. Overall, the project was designed with a scalable strategy using Redis, SWR, and Nuxt3 to reduce server workload.

In addition to the core architecture, I implemented an AI-powered resume scanning feature for Pernambucanas' talent acquisition platform ("Vem Pra Família"). The solution enabled automated parsing of candidate resumes, extracting skills, work history, and applicant details into structured data, substantially accelerating the HR screening pipeline.

- Languages: Typescript, Javascript, Node.js, C#

- Artificial Intelligence: AI Resume Scanning, OpenAI API, Structured Outputs

- Databases: Redis, PostgreSQL

- Frameworks & Architecture: Tailwind, Nuxt (2/3), Vue.js (Vue 2/3), .Net, Micro-Frontends, Clean Architecture, SWR, Hexagonal Architecture, Event-Driven Architecture, REST API Development

- Cloud & DevOps: Azure Cloud, Terraform, Bicep, CloudFormation, Git
